### Lección aprendida
- La tabla `configuracion_ronda` ya existía en el schema original con columnas diferentes (`fecha_creacion` vs `created_at`, `nombre` NOT NULL, etc.). El migration-v2.sql referenciaba `config_ronda` pero la tabla real es `configuracion_ronda`. Siempre verificar schema existente antes de crear models.
- Puppeteer funciona en el servidor headless: `npm install puppeteer` en workspace, usa Chromium bundled. No necesita apt install.
- Para login correcto en screenshots: hacer login via API primero, luego inyectar token+userData en localStorage (token, osyris_user, user, userRole).
